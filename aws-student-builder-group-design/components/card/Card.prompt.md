Flat dark card with a short accent bar on top — the base unit for event listings, resource links and team bios.

```jsx
<Card eyebrow="Workshop" title="Intro to Amazon S3" description="Hands-on session for first-time builders." accent="sky" />
```

`accent` picks which brand color tops the card. Pass `footer` for a CTA row, or `children` for custom body content instead of `description`.
