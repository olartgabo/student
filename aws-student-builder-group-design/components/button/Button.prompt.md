Monospace-labelled action button for the AWS Student Builder Group brand — use for CTAs like "Join the group" or "Register".

```jsx
<Button variant="primary" size="md" onClick={() => {}}>Join the group</Button>
```

Variants: `primary` (orange fill, for the main action per screen), `secondary` (outlined, slate border), `outline` (white border, for use on dark/photo backgrounds), `ghost` (text-only, sky blue, for tertiary actions). Sizes: `sm`, `md`, `lg`. Set `disabled` to grey it out.
